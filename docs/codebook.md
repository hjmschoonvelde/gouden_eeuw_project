# Codebook Summary

The project codes "Gouden Eeuw" references as mnemonic tropes only when they do argumentative, evaluative, or identity work in parliamentary speech.

## Inclusion

Include a speech when a Golden Age signifier is used as a meaningful resource in parliamentary interaction: for example, to legitimise a position, criticise an actor, benchmark the present, draw a boundary, or moralise the past.

Exclude a speech when the reference is only factual, bibliographic, or informational.

## Temporal Grammar

| Code | Label | Operational meaning |
|---|---|---|
| TG1 | Continuity | The past is linked to the present through lineage, durable identity, analogy, or continuing national vocation. |
| TG2 | Return | The Golden Age is treated as a model to recover, renew, restore, or re-achieve. |
| TG3 | Break | The past is presented as incommensurable, outdated, morally unusable, or no longer a valid guide. |
| TG4 | Struggle | The speech foregrounds conflict over the term, its meaning, ownership, commemoration, or legitimate use. |
| TG5 | Other | A residual category for symbolic uses without a clear past-present-future linkage. |

The final analytic dataset excludes TG5.

## Symbolic Work

| Code | Label | Operational meaning |
|---|---|---|
| SW1 | Governing legitimation | The trope justifies or rationalises a concrete policy, institutional choice, budget stance, or governing programme. |
| SW2 | Competitive positioning | The trope is used to praise, blame, attack, defend, or position parties, MPs, cabinets, or other political actors. |
| SW3 | Identity and boundary making | The trope defines collective identity, belonging, Dutchness, cultural citizenship, or symbolic in/out groups. |
| SW4 | Moral memory | The trope organises moral evaluation of the past, including pride, shame, responsibility, acknowledgement, apology, debt, or repair. |
| SW5 | Other | A residual category for symbolic work that does not fit SW1-SW4. |

## Dominance Rules

One primary temporal grammar and one primary symbolic-work code are assigned to each included speech. If a speech contests the meaning, naming, ownership, or legitimate use of "Gouden Eeuw", TG4 takes priority over continuity, return, or break language. For symbolic work, the dominant target determines the primary code: policy, actor, collective identity, or moral accounting.
